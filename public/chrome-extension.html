ONE-TIME SETUP

Install in Chrome

  1. 1
    Download and unzip

    Download the extension ZIP above, then double-click it to create the extension folder.

  2. 2
    Open Chrome Extensions

    Enter chrome://extensions in Chrome's address bar.

  3. 3
    Turn on Developer mode

    Use the Developer mode switch in the upper-right corner.

  4. 4
    Load the folder

    Click Load unpacked and select the unzipped MK extension folder.

Using a downloaded PDF? Open the extension's Details page in Chrome and turn on Allow access to file URLs.

How it works

The extension reads the current page text and captures the visible tab only after you click Create. The screenshot is deleted immediately after extraction. Saved records and generated documents use the website's existing seven-day retention.
